# WedHub ERP — Home / Today Screen

A fast, responsive operational dashboard and counter-management ERP interface for wedding rental stores.

## 🚀 Features

- **Live Daily Timeline**: Visual timeline slots for pickups, returns, and wash returns.
- **Overdue Management**: Full-width alert band for overdue rentals with instant action buttons and expandable details.
- **Laundry Pipeline**: 3-stage tracking (`Returned, not washed` → `At laundry` → `Back on rack`).
- **Counter Workflow**: Pickup balance collection (UPI / Cash), security deposit handling, and return inspection notes.
- **Responsive Views**: Supports both Desktop and Mobile interfaces.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Icons**: Lucide React / Lucide
- **Styling**: Vanilla CSS tokens (Paper & Ink editorial theme with Playfair Display & DM Sans typography)

## 💻 Getting Started Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.
